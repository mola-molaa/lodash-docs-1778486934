<Heading level="2">
    使用示例
</Heading>

<Paragraph>
    柯里化函数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">var curry = _.curry(function(a, b, c) {</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">  return a + b + c;</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">});</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">var addFive = curry(2)(3);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">addFive(1);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// => 6</Mark><Mark>`</Mark>
</Paragraph>

<Paragraph>
    节流函数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">var throttled = _.throttle(function() {</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">  console.log('throttled');</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">}, 1000);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// 1000ms 内最多执行一次</Mark><Mark>`</Mark>
</Paragraph>

<Paragraph>
    组合函数：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">var negate = function(n) { return -n; };</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">var square = function(n) { return n * n; };</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">var negativeSquare = _.flow(square, negate);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">negativeSquare(5);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// => -25</Mark><Mark>`</Mark>
</Paragraph>

<Heading level="2">
    防抖与节流对比
</Heading>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>防抖 (debounce)</Mark>
        </TableCell>
        <TableCell>
            在最后一次调用后等待指定时间才执行，期间有新调用则重置计时
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>节流 (throttle)</Mark>
        </TableCell>
        <TableCell>
            在指定时间间隔内最多执行一次，保证执行频率
        </TableCell>
    </TableRow>
</Table>

<Paragraph>
    典型使用场景：
</Paragraph>

<BulletedList>
    防抖：搜索输入、窗口调整、表单验证
</BulletedList>
<BulletedList>
    节流：滚动事件、鼠标移动、动画帧
</BulletedList>
