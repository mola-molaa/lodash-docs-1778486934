<Heading level="1">
    对象方法 (Object Methods)
</Heading>

<Paragraph>
    Lodash 提供了强大的对象操作工具，涵盖属性访问、修改、合并等功能。
</Paragraph>

<Heading level="2">
    使用示例
</Heading>

<Paragraph>
    安全获取嵌套属性：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">var object = { 'a': [{ 'b': { 'c': 3 } }] };</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">_.get(object, 'a[0].b.c', 'default');</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// => 3</Mark><Mark>`</Mark>
</Paragraph>

<Paragraph>
    深度合并对象：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">var object = {</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">  'a': [{ 'b': 2 }, { 'd': 4 }]</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">};</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">var other = {</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">  'a': [{ 'c': 3 }, { 'e': 5 }]</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">};</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">_.merge(object, other);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// => { 'a': [{ 'b': 2, 'c': 3 }, { 'd': 4, 'e': 5 }] }</Mark><Mark>`</Mark>
</Paragraph>

<Paragraph>
    挑选属性：
</Paragraph>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">_.pick({ 'a': 1, 'b': 2, 'c': 3 }, ['a', 'c']);</Mark><Mark>`</Mark>
<Mark>`</Mark><Mark color="blue">// => { 'a': 1, 'c': 3 }</Mark><Mark>`</Mark>
</Paragraph>
