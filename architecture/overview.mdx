<Heading level="2">
    FP 模块架构
</Heading>

<Paragraph>
    FP 模块位于 <Mark color="blue">fp/</Mark> 目录，提供函数式编程风格的方法。
</Paragraph>

<Heading level="3">
    核心文件
</Heading>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>_baseConvert.js</Mark>
        </TableCell>
        <TableCell>
            核心转换函数，将标准 Lodash 方法转换为 FP 风格
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>_mapping.js</Mark>
        </TableCell>
        <TableCell>
            方法映射配置，定义别名、参数顺序、柯里化等
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>_convertBrowser.js</Mark>
        </TableCell>
        <TableCell>
            浏览器环境转换入口
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>_placeholder.js</Mark>
        </TableCell>
        <TableCell>
            占位符定义
        </TableCell>
    </TableRow>
</Table>

<Divider blockColor="light_grey" />

<Heading level="2">
    FP 转换特性
</Heading>

<Paragraph>
    FP 模块通过 <Mark color="blue">baseConvert</Mark> 函数实现以下转换：
</Paragraph>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>柯里化 (curry)</Mark>
        </TableCell>
        <TableCell>
            自动将多参数函数转换为柯里化形式
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>参数重排 (rearg)</Mark>
        </TableCell>
        <TableCell>
            将参数顺序改为 iteratee-first data-last
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>固定参数 (fixed)</Mark>
        </TableCell>
        <TableCell>
            限制函数接受的参数数量
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>不可变 (immutable)</Mark>
        </TableCell>
        <TableCell>
            操作前克隆数据，避免修改原数据
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>参数上限 (cap)</Mark>
        </TableCell>
        <TableCell>
            限制 iteratee 接受的参数数量
        </TableCell>
    </TableRow>
</Table>

<Heading level="2">
    构建系统
</Heading>

<Paragraph>
    Lodash 使用自定义构建脚本，位于 <Mark color="blue">lib/</Mark> 目录。
</Paragraph>

<Heading level="3">
    主要构建任务
</Heading>

<BulletedList>
    <Mark bold>build:main</Mark> - 构建主库
</BulletedList>
<BulletedList>
    <Mark bold>build:fp</Mark> - 构建 FP 模块
</BulletedList>
<BulletedList>
    <Mark bold>build:main-modules</Mark> - 构建主库模块化版本
</BulletedList>
<BulletedList>
    <Mark bold>build:fp-modules</Mark> - 构建 FP 模块化版本
</BulletedList>

<Heading level="3">
    构建输出
</Heading>

<Paragraph textAlign="left" blockColor="light_grey">
<Mark>`</Mark><Mark color="blue">$ npm run build</Mark><Mark>`</Mark>
</Paragraph>

<Paragraph>
    将生成以下文件到 <Mark color="blue">dist/</Mark> 目录：
</Paragraph>

<BulletedList>
    lodash.js - 完整开发版本
</BulletedList>
<BulletedList>
    lodash.min.js - 完整生产版本
</BulletedList>
<BulletedList>
    lodash.core.js - 核心开发版本
</BulletedList>
<BulletedList>
    lodash.core.min.js - 核心生产版本
</BulletedList>
<BulletedList>
    lodash.fp.js - FP 模块浏览器版本
</BulletedList>
<BulletedList>
    mapping.fp.js - FP 映射配置浏览器版本
</BulletedList>
