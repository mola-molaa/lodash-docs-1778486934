<Heading level="1">
    Lodash v4.18.1
</Heading>

<Paragraph>
    <Mark bold>Lodash</Mark> 是一个现代的 JavaScript 实用工具库，以 <Mark bold>模块化</Mark>、<Mark bold>高性能</Mark>和<Mark bold>功能丰富</Mark>著称。它可以让 JavaScript 开发变得更简单，帮你轻松处理数组、数字、对象、字符串等。
</Paragraph>

<Paragraph>
    Lodash 以 <Mark color="blue">UMD</Mark> 模块形式导出，支持多种模块规范和环境。
</Paragraph>

<Divider blockColor="light_grey" />

<Heading level="2">
    主要特性
</Heading>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>模块化设计</Mark>
        </TableCell>
        <TableCell>
            可按需加载单个方法，支持 tree-shaking
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>高性能</Mark>
        </TableCell>
        <TableCell>
            经过优化的算法实现，性能优于原生和一些同类库
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>一致性 API</Mark>
        </TableCell>
        <TableCell>
            统一的参数顺序和返回值设计
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>FP 支持</Mark>
        </TableCell>
        <TableCell>
            提供函数式编程模块，自动柯里化、参数重排
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>多环境支持</Mark>
        </TableCell>
        <TableCell>
            浏览器、Node.js、Deno 等现代 JavaScript 环境
        </TableCell>
    </TableRow>
</Table>

<Divider blockColor="light_grey" />

<Heading level="2">
    构建版本
</Heading>

<Paragraph>
    Lodash 提供多种构建版本以满足不同场景需求：
</Paragraph>

<Table>
    <TableRow>
        <TableCell>
            <Mark bold>完整构建</Mark>
        </TableCell>
        <TableCell>

        </TableCell>
        <TableCell>
            包含所有方法
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>核心构建</Mark>
        </TableCell>
        <TableCell>
            lodash.core.js (~4 kB gzipped)
        </TableCell>
        <TableCell>
            仅包含核心方法
        </TableCell>
    </TableRow>
    <TableRow>
        <TableCell>
            <Mark bold>FP 构建</Mark>
        </TableCell>
        <TableCell>

        </TableCell>
    </TableRow>
</Table>
